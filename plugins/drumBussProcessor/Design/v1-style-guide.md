# Style Guide v1 (Based on NeoGrid Minimal)

## Color Palette
- **Primary (Cyan):** `#00FFFF`
- **Secondary (Magenta):** `#FF0099`
- **Background:** `#111115`
- **Surface:** `#1E1E24`
- **Surface Highlight:** `#2A2A33`
- **Text Primary:** `#F0F0F5`
- **Text Secondary:** `#A0A0B0`
- **Border:** `#333340`

## Typography
- **Headings:** Inter, sans-serif (700)
- **Body:** Inter, sans-serif (400/500)
- **Labels:** Inter, sans-serif (700, Uppercase, Looser tracking)

## Component Styles
- **Border Radius:** 4px
- **Border Width:** 1px
- **Shadows:** Deep dropshadows (`0 30px 60px -10px rgba(0,0,0,0.8)`) for depth.
- **Glows:** Subtle blooms on active elements.

## Layout Principles
- **Grid:** Strict alignment.
- **Spacing:** Generous padding (32px modules).
- **Decorations:** Cosmetic "screws" in corners, inset panels for grouping.
